# Travel Bookings Analysis Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyze 300,000+ flight booking records.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed price patterns by airline, class, stops, and days left
- Created 4 KPI cards (Average Price, Max Price, Min Price, Total Flights)
- Built bar chart, donut chart, column chart, and line chart
- Added slicer for Airline filter

## Key Insights
- Vistara has highest average price (~27K)
- Economy class is 88% of bookings
- Direct flights cost more than 1-stop flights
- Prices drop as departure date gets closer
